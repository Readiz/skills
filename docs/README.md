## 활용 방법

`docs/`는 읽고 참고하는 문서 모음입니다. 설치할 스킬은 저장소의 `skills/`에 있습니다. 이 문서를 읽거나 저장소를 내려받아도 사용자 설정, 모델, 기존 대화와 예약 작업은 바뀌지 않습니다.

설정 예시를 적용할 때는 설치된 버전과 사용 가능한 모델, 실제 연결 도구를 먼저 확인하고 기존 파일과 병합합니다. 문서의 정리 시점과 자신의 실행 환경이 다를 수 있으므로 각 문서에 연결한 공식 문서도 함께 확인합니다.

## 문서 관리 기준

- 최신 운영 의도를 중심으로 정리하고, 대체된 제안은 현재 설정 예시에 섞지 않습니다.
- 선호하는 작업 방식과 제품이 지원하는 기능, 실제 설치 결과를 구별합니다. 파일 저장과 실제 위임, 브라우저 관찰과 추론, 호출 성공과 사용량 창 변경을 각각 확인합니다.
- 인증정보, 내부 서비스 주소, 개인 기기명, 기기별 절대 경로와 비공개 자료 링크는 포함하지 않습니다. 홈 디렉터리 기준 경로는 재사용 가능한 설정 위치를 설명할 때 사용합니다.
- 문서 갱신 시 원래 의도와 공식 근거, 상대 링크와 설정 예시의 문법을 확인합니다. 사용자 환경에 적용한 결과는 별도 검증 뒤 보고합니다.
